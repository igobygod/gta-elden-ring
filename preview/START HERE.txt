igobygod — GTA × Elden Ring
Windows preview 0.2.7

1. Open igobygod Setup.exe on Windows.
2. Select GTA V Legacy and the Elden Ring Game folder.
3. Choose a new or empty mod installation folder.
4. Enable automatic tool setup and click Install mod.
5. Use Play mod or the Play igobygod Mod desktop shortcut.

First setup needs internet and 35 GB free working space. It downloads several
GB of supporting tools. Microsoft components may request administrator access
or a restart. Completed verified downloads are reused after a retry.

Requires Windows 10/11 x64, .NET Framework 4.8 and a DirectX 12 GPU supporting
feature level 12.0. Elden Ring must run normally before testing the mod.
Parallels on Apple silicon does not provide the required graphics capability.

The mod uses offline mode and a separate save. Normal game requirements apply.
Setup supports one exact Elden Ring executable; details are in README.md.
GTA Enhanced is unsupported. The installer is unsigned.

Installation and asset checks passed in a Windows VM. Gameplay on supported
Windows hardware remains untested.

To remove the mod, close the game, delete its installation folder and shortcut.
Microsoft tools can be removed through Windows Installed Apps. The separate
mod save can be backed up independently.
